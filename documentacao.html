Visão Geral da Organização

Para atender à exigência de arquivos separados, o sistema foi concebido sem acoplamento monolítico. A aplicação está dividida em 3 pilares fundamentais, todos situados diretamente na pasta do projeto:

Arquivo Tecnologia Tamanho Papel Fundamental no Sistema
index.html <HTML5> ~35 KB Esqueleto Estrutural & Semântica: Contém a marcação hierárquica das telas de Login, Dashboard, Clientes, Produtos, Fornecedores, Vendas e Modais.
style.css CSS3 ~20 KB Design System & Responsividade: Define variáveis globais (cores, sombras, raios de borda), flexbox, grid, regras para celular/desktop e animações.
script.js Vanilla JS ~12 KB Comportamento & Interatividade: Lógica de autenticação com validação, alternância entre telas, menu drawer responsivo, busca em tempo real e gráfico SVG.
Documentacao_InfoStore.pdf PDF Arquivo Atual Dossiê para referência do desenvolvedor e transição rápida para novos prompts.
Zero Dependências Externas: A aplicação funciona 100% offline. Não exige npm install, servidor Node.js ou downloads adicionais para ser renderizada com perfeição visual no Google Chrome, Microsoft Edge ou Firefox.

Como os Três Arquivos se Conectam

O arquivo principal é o index.html. Ele estabelece as conexões externas de forma explícita:

  • Na tag <head>: Conecta a folha de estilos através de <link rel="stylesheet" href="style.css">. Isso faz com que todo o visual e regras responsivas sejam aplicados aos elementos.
  • No final do <body>: Invoca a lógica com <script src="script.js"></script>. Colocá-lo ao final garante que todos os nós HTML já tenham sido carregados antes do script tentar manipulá-los (garantindo velocidade e evitando erros de elemento nulo).

Fluxo Funcional das Telas

  1. Acesso Inicial: O usuário visualiza o card de Login InfoStore pré-preenchido com o usuário wendel.
  2. Autenticação Simulada: Ao digitar a senha e clicar no botão preto Entrar, um indicador de carregamento é acionado e a tela de Dashboard é exibida suavemente.
  3. Navegação Drawer / Sidebar: Em dispositivos móveis, o botão hamburger (☰) abre a barra lateral preta (#09090b) com backdrop translúcido. No desktop, a barra lateral é mantida fixada.
  4. Abas Disponíveis: O usuário navega entre Dashboard, Clientes, Produtos, Fornecedores e Vendas instantaneamente.
  5. Logout: O botão Sair no rodapé da barra lateral encerra a sessão e retorna à tela de login com uma notificação flutuante (toast).
2. Conceitos HTML5: Por que usar Class, Div e Semântica?
Página 3

1. Por que usar class e qual a diferença para id?

Tanto class quanto id são atributos globais do HTML usados para identificar elementos. No entanto, sua finalidade técnica e interpretação pelos navegadores são distintas:

Atributo Regra de Ocorrência Finalidade Principal Exemplo no Projeto InfoStore
class Múltipla & Reutilizável: O mesmo nome de classe pode e deve ser aplicado em dezenas de elementos diferentes. Estilização em Massa (CSS): Define um padrão visual compartilhado (ex: formato de botões, cards, sombras, campos de texto). class="form-input" aplicado tanto no campo de usuário quanto de senha.
class="metric-card" aplicado nos 4 cards de indicadores.
id Único no Documento: Cada ID só pode existir uma única vez por página HTML. Alvo Específico (JavaScript / DOM): Permite que o JavaScript encontre com precisão cirúrgica aquele elemento exato via document.getElementById(). id="username-input" para ler o texto digitado.
id="login-form" para escutar o evento de envio (submit).
id="app-sidebar" para abrir/fechar o menu drawer.
Regra de Ouro dos Desenvolvedores: Use classes para tudo o que envolve estilo visual no CSS. Use IDs apenas quando precisar manipular um elemento exclusivo via JavaScript ou linkar uma âncora direta.

2. Por que e quando usamos a tag <div>?

A palavra div é uma abreviação de division (divisão). Tecnicamente, ela é um contêiner genérico de bloco que não possui significado semântico intrínseco.

Quando DEVE ser usada:

  • Agrupador de Layout (Flexbox & Grid): Quando precisamos que dois ou mais elementos fiquem lado a lado ou organizados em colunas (ex: <div class="metrics-grid"> para agrupar os 4 cards).
  • Wrapper de Posicionamento: No campo de senha, usamos <div class="input-wrapper password-wrapper"> com position: relative para posicionar o botão do olho (position: absolute) exatamente à direita do campo de texto.
  • Camadas e Efeitos Visuais: Para o fundo escurecido do menu lateral (<div id="sidebar-backdrop">) e toasts flutuantes.

Quando NÃO deve ser usada:

Evita-se o fenômeno conhecido como "Div Soup" (sopa de divs), que ocorre quando o desenvolvedor usa <div> para botões (em vez de <button>), para cabeçalhos (em vez de <header>) ou para menus (em vez de <nav>). Isso destrói a acessibilidade para deficientes visuais e prejudica a interpretação do navegador.

3. A Semântica do HTML5 e a Interpretação dos Navegadores

Elementos semânticos carregam significado sobre o papel daquele conteúdo. Os navegadores modernos e motores de busca (Google) constroem a Accessibility Tree (Árvore de Acessibilidade) com base nessas tags:

Tag Semântica O que ela representa Como o Navegador interpreta
<header> Cabeçalho de uma seção ou página. Interpreta como o marco de topo ou introdução daquele bloco de informações.
<nav> Área de links e navegação primária. Leitores de tela permitem que usuários cegos pulem direto para o menu usando atalhos.
<main> O conteúdo central e dominante do documento. Sinaliza a área principal, excluindo cabeçalhos e barras laterais repetitivas.
<aside> Conteúdo lateral ou tangencial. Ideal para menus drawer e sidebars complementares ao fluxo principal.
<section> Uma seção temática independente. Agrupa blocos de dados como Dashboard, Clientes, Produtos e Vendas.
<table> Dados tabulares bidimensionais. Organiza dados com cabeçalhos <th> e linhas <tr> para leitura estruturada.
<button> Elemento interativo que dispara uma ação. Garante foco nativo pelo teclado (tecla Tab) e ativação pela tecla Enter ou Espaço.
3. Guia de Linhas Editáveis: Login & Dashboard
Página 4

Linhas Editáveis no Arquivo index.html

Abaixo estão os trechos exatos do código com as partes que você pode alterar livremente para personalizar seu sistema (trocar nomes, textos, valores e substituir ícones por imagens reais):

1. Tela de Login (Logotipo, Nomes e Textos) Editável

Localize as linhas 20 a 33 de index.html para alterar o nome do sistema ou trocar o ícone do monitor por sua própria imagem: 

<!-- Cabeçalho da Tela de Login -->
<header class="login-header">
  <div class="header-icon-circle">
    <!-- DICA: Para colocar sua logo em imagem (PNG/JPG), troque o <svg> por: -->
    <!-- <img src="minha-logo.png" alt="Logo" style="width: 36px; height: 36px;"> -->
    <svg class="icon-monitor" viewBox="0 0 24 24" ...>...</svg>
  </div>
  <h1 class="brand-title">InfoStore</h1>           <!-- [EDITAR] Nome da Empresa -->
  <p class="brand-subtitle">Sistema de Gestão</p>  <!-- [EDITAR] Subtítulo -->
</header>

Para alterar o usuário padrão pré-carregado no formulário (linha 47): 

<input type="text" id="username-input" class="form-input" value="wendel"> <!-- Troque "wendel" por seu usuário -->
2. Avatar do Usuário no Topo do Sistema Editável

Localize as linhas 190 a 195 de index.html para trocar a letra "A" por uma foto real do administrador: 

<!-- Para manter a letra inicial: -->
<div class="user-avatar" title="Wendel (Administrador)">
  <span>A</span> <!-- [EDITAR] Altere para a letra desejada -->
</div>

<!-- OU para usar uma foto real do usuário: -->
<div class="user-avatar">
  <img src="avatar.jpg" alt="Foto" style="width:100%; height:100%; border-radius:50%; object-fit:cover;">
</div>

const salesData = [

6. Tabela de Estoque Baixo (Produtos, Categorias e Alertas) Editável

Localize as linhas 350 a 395 de index.html. Cada linha <tr> representa um produto monitorado: 

<tr>
  <td class="font-medium">Notebook Dell Inspiron</td>  <!-- [EDITAR] Nome do Produto -->
  <td class="text-secondary">Notebooks</td>            <!-- [EDITAR] Categoria -->
  <td><span class="stock-pill stock-warning">12</span></td>  <!-- [EDITAR] Quantidade e Estilo -->
  <td><span class="status-badge badge-active">Ativo</span></td> <!-- Use badge-inactive para Inativo -->
</tr>

Opções de Estilo para Pílulas de Estoque:

  • class="stock-pill stock-critical" → Fundo vermelho claro (Estoque Zerado / Crítico).
  • class="stock-pill stock-danger" → Fundo rosa/vermelho (Estoque muito baixo, ex: 8 un).
  • class="stock-pill stock-warning" → Fundo amarelo/âmbar (Estoque de alerta, ex: 12 a 25 un).
  • class="stock-pill stock-safe" → Fundo verde (Estoque seguro/normal).
5. Customização de Cores no CSS & Roteiro Nova Conversa
Página 6

Personalização Visual no style.css

Todas as cores globais estão concentradas no início do arquivo style.css (linhas 6 a 35). Basta substituir o código hexadecimal (ex: #5850ec) pela cor de sua preferência: 

:root {
  --bg-app: #f5f6fb;              /* Cor de fundo de toda a página */
  --bg-card: #ffffff;             /* Cor de fundo dos cards brancos */
  --bg-sidebar: #09090b;          /* Cor do menu lateral escuro */
  --primary: #5850ec;             /* Cor principal (Indigo / Destaques) */
  --teal-icon: #10b981;           /* Cor do ícone de Produtos */
  --amber-icon: #f59e0b;          /* Cor do ícone de Faturamento */
  --badge-green-bg: #e8fbf0;      /* Fundo da badge Concluída */
  --badge-yellow-bg: #fff9e6;     /* Fundo da badge Pendente */
}
